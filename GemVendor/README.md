# GemVendor 宝石商店

D2RMM 模组：让 Act 1 的阿卡拉出售所有宝石。

## 覆盖范围

- 紫晶、黄晶、蓝晶、绿晶、红晶、钻石、骷髅（共 7 类）。
- 每种包含 5 个品级：碎片 / 有瑕 / 普通 / 无瑕 / 完美。
- 也包含 Reimagined 风格的额外宝石行（若有）。

## 配方/机制

- 不改物品属性，只改 `misc.txt` 里的商店字段：
  - `spawnable=1`（原本 `0`，所以商店不生成）
  - `AkaraMin` / `AkaraMax`（每种库存数量）
  - `PermStoreItem=1`（永久上架物品）
  - `multibuy=1`（可批量购买）
  - `level=0`（任何难度都能上架）
- 宝石类型已在 Misc 商店页，无需改 `storepage` / `itemtypes`。

## 配置

- `stockMin` / `stockMax`：每种宝石的库存数量，默认 `1~3`。
- `cost`：`0` 表示保留各宝石原价；大于 `0` 则统一改成该金币价。
  （原版完美骷髅约 10 万金，建议按需设价。）
