# ReqLower 装备需求等级降低

D2RMM 模组：用不同品级骷髅作为催化剂，按梯度降低任意装备的需求等级。

## 配方

```
武器(weap) / 护甲(armo) / 戒指(rin) / 护身符(amu) + 骷髅 -> 需求降低
  skc 碎片骷髅 -> -1   (最低档)
  skf 有瑕骷髅 -> -2
  sku 普通骷髅 -> -3
  skl 无瑕骷髅 -> -4
  skz 完美骷髅 -> -5   (最高档)
```

每档降低 = 品级 × `reductionStep`（默认 1）。即默认 `-1/-2/-3/-4/-5`，
设步长 2 则变成 `-2/-4/-6/-8/-10`。

## 实现

- `ItemStatCost.txt` 的 `item_levelreq` 改为 32 位可保存/发送 stat：
  `Send Bits=32`、`Save Bits=32`、`Signed=1`、`Divide=1024`、
  `1.09-Save Bits=6`、`1.09-Save Add=20`，并清除显示函数。
- `levelreq` 属性是 `func1=1`（叠加），用负值降低；配方按骷髅品级写不同负值。

## 注意

- 把 `item_levelreq` 变成 32 位可保存 stat 会**改变物品存档格式**：旧角色/旧存档
  可能无法正常读取。
- **仅用于新建存档/新角色**。
