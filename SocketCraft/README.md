# SocketCraft 打孔合成

D2RMM 模组：用符文给任意可打孔物品打孔。

## 配方

```
武器(weap)  + 1~6号符文  ->  打 1~6 孔（保留原版武器上限）
护甲(armo)  + 1~6号符文  ->  打 1~6 孔（保留原版护甲上限）
手套(glov)  + 1~3号符文  ->  打 1~3 孔
鞋子(boot)  + 1~3号符文  ->  打 1~3 孔
腰带(belt)  + 1~2号符文  ->  打 1~2 孔
戒指(rin)   + 1号符文    ->  打 1 孔
护身符(amu) + 1号符文    ->  打 1 孔
```

符文会被消耗，物品本身保留（原地打孔，不改变底材/品阶/词缀）。
配方按通用的物品类型代码匹配，无需限定具体底材，不要求物品未打孔。
原版武器/护甲保持原版最大孔数，不额外抬升。手套/鞋子固定 3 孔、
腰带 2 孔、戒指/护身符 1 孔、原版不可打孔的投掷武器（飞斧、飞刀、标枪等）3 孔。

## 打孔上限

可打孔数 = `min(物品占用的格子数, 配置的最大孔数上限)`。

- 格子数 = `invwidth × invheight`（例如：戒指 1×1 = 1 孔，腰带 2×1 = 2 孔，
  手套/靴子 2×2 = 4 孔，单手武器 2×3 = 6 孔，双手武器/盾 2×4 = 8 孔）。
- 默认最大上限为 8（符文只到 8 号），可在模组配置里改为 1~8。

## 新支持打孔的部位

原本不能打孔的 手套(glov)、鞋子(boot)、戒指(ring)、项链(amul)、腰带(belt)
现在也能通过该配方打孔。可在配置里关闭 `enableNewTypes` 恢复原版行为。

## 实现机制

- 在 `cubemain.txt` 添加 `weap`/`armo`（1~6 孔）、`glov`/`boot`（1~3 孔）、
  `belt`（1~2 孔）、`rin`/`amu`（1 孔），共 22 条通用配方。
- 仅抬升新开槽位与投掷武器的 `gemsockets` 与 `itemtypes MaxSockets1/2/3`
  到固定上限；原版武器/护甲的数据保持原样。
- 修正镶嵌兼容性：手套/鞋子/腰带/戒指/项链底材设为 `hasinv=1`（否则能打孔
  但无法镶嵌宝石/符文），并设置镶嵌属性类别：手套/鞋子/腰带为护甲效果
  （`gemapplytype=1`），戒指/护身符为武器效果（`gemapplytype=0`）。
- 投掷武器（`jave`/`tkni`/`taxe`/`ajav`）默认 `hasinv` 已为 1，将其
  `gemsockets` 与 `itemtypes MaxSockets` 抬升到格子数即可打孔/镶嵌。

## 已知限制

- 配方不限制物品是否已打孔，重复使用会覆盖已有孔数。
- 8 孔 / 饰品打孔为游戏机制外行为，若渲染异常可在配置中调低 `maxSockets`。
